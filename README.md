# 基因组数据分析系统

面向污水处理污泥的前端演示分析台：支持 **16S 扩增子** 与 **宏基因组** 两种模式，测序文件拖拽上传，分析模块可拖拽编排。白底微蓝风格。

## 功能

- 拖拽上传 FASTQ / FASTA（含 `.gz`）
- 样本元数据配置（工艺段、批次、平台）
- 可拖拽流水线：从模块库拖入、排序、删除；双击模块也可添加
- 一键运行（前端模拟进度）并展示：
  - KPI、门级组成、多样性、功能/ARG 雷达图
  - 关键物种或抗性基因表、解读摘要
- 「载入演示数据」快速体验

## 本地打开

本项目为纯静态页面，无需 Node。任选其一：

```bash
# Python
cd sludge-omics
python3 -m http.server 5173
```

浏览器访问：http://127.0.0.1:5173

或直接用浏览器打开 `index.html`（若 CDN 图表加载受限，优先用本地服务器）。
